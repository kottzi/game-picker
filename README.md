# Game Picker

Веб-решение для компаний друзей, которые полчаса решают, во что они хотят поиграть.
Собираешь лобби, приглашаешь друзей по коду, каждый пикает игры из общего
пула (пересечение Steam-библиотек участников), а в конце — ТОП по числу 
совпавших пиков вместо очередной возни в чате.

## Как это работает?

1. Авторизация через Steam.
2. Хост создает лобби, получает код приглашения.
3. Участники заходят по коду. Пул игр — пересечение того, что есть у всех
   в Steam-библиотеке.
4. Каждый пикает игры, в которые готов поиграть. Чужие пики не видны до
   закрытия голосования.
5. Хост закрывает голосование — если пикнутых игр 3 и больше, показываются
   топ-3 по числу совпадений; если игр меньше — показываются все
   (в пределе: одна игра у всех = 100%).
6. Все, что происходит в лобби (кто зашел, кто пикнул, готов результат),
   разлетается остальным участникам в реальном времени через SSE.

## Локальный запуск:

```bash
cd docker
cp .env.example .env   # Необходимо заполнить переменные в .env
docker compose up -d --build
```
